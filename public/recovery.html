Recover your browser workspace

This page reads the old Resume Builder data at . It never changes or deletes browser storage, and it does not contact the database.

Use the same browser and exact address where you built your resumes. Both the hostname and port must match. Download a backup here, then import it using Backup & recovery in the updated app.

If another app is using the original port

You can recover data without stopping that app:

  1. Drag Recover browser resumes to your browser's bookmarks bar.
  2. Open the original address (such as http://localhost:3000) in the browser where you built your resumes.
  3. Click that bookmark, then Download browser backup.
  4. Return to the updated Resume Builder and use Backup & recovery → Import backup.

The bookmark runs this local, read-only recovery tool at the old browser address. Resume data stays in the browser until you download it. If the old app blocks the tool with its content security policy, serve this project's recovery page at the original address instead.
